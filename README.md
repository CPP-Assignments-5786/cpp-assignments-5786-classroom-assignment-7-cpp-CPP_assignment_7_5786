# מטלה שמינית - תבניות, איטרטורים, פונקציות תבניתיות ומחסנית

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.


## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" ומטרתה להדגים את הכוח של **תבניות (Templates)** בשפת C++. המטלה מתמקדת ביישום מבני נתונים גנריים — מחסנית (Stack) ותור (Queue) — יחד עם איטרטורים מותאמים אישית ופונקציות תבניתיות חופשיות.

## מבנה המטלה
במטלה זו תתבקשו לממש מספר קבצי `.hpp` (כי תבניות חייבות להיות מוגדרות בקבצי header). המטלה מדגימה:
- **תבניות מחלקה (Class Templates)** - מחלקות גנריות שעובדות עם כל טיפוס
- **תבניות פונקציה (Function Templates)** - פונקציות גנריות
- **איטרטורים (Iterators)** - מחלקות פנימיות שמאפשרות מעבר על איברי המכולה
- **שימוש בנושאים ממטלות קודמות** - חריגות, ירושה, מרחבי שמות, בנאים/מפרקים, הקצאה דינמית

## דרישות והנחיות
- לממש את הקוד בקבצים שסופקו
- **שימו לב:** מכיוון שמדובר בתבניות, כל המימוש חייב להיות בקבצי `.hpp` (ולא בקבצי `.cpp` נפרדים)
- הקבצים שעליכם לממש הם הקבצים שבהם יש פונקציות שמסומנות עם הערה "Must be implemented"
- לוודא שהקוד מתקמפל ופועל ללא שגיאות
- לעבור בהצלחה את הטסטים הכתובים בקובץ test.cpp

## תכונות C++ שיש להדגים
1. **תבניות מחלקה (Class Templates)** - `Stack<T>`, `Queue<T>`, `Container<T>`
2. **תבניות פונקציה (Function Templates)** - פונקציות חופשיות גנריות
3. **איטרטורים (Iterators)** - מחלקת Iterator פנימית עם `begin()` ו-`end()`
4. **הקצאה דינמית עם תבניות** - מערכים דינמיים מטיפוס `T`
5. **חריגות (Exceptions)** - טיפול בשגיאות כמו גישה למחסנית ריקה
6. **מרחבי שמות (Namespaces)** - שימוש במרחב שמות `containers`
7. **בדיקות יחידה (Unit Testing)** - שימוש בספריית doctest

## קבצים במטלה

### קבצים שסופקו (עם חלקים לממש):
- **Container.hpp** - מחלקת מכולה גנרית בסיסית עם איטרטור
- **Stack.hpp** - מחסנית גנרית המבוססת על Container
- **Queue.hpp** - תור גנרי המבוסס על Container
- **Algorithms.hpp** - פונקציות תבניתיות חופשיות (find, count, transform ועוד)
- **main.cpp** - תוכנית ראשית המדגימה שימוש בכל הפונקציות עם הערות המציינות את הפלט הצפוי
- **test.cpp** - קובץ בדיקות
- **doctest.h** - ספרייה לביצוע בדיקות אוטומטיות
- **Makefile** - קובץ לקימפול והרצה אוטומטית של הפרויקט

### מה עליכם לממש:
- את הפונקציות המסומנות כ-"Must be implemented" בכל קובץ `.hpp`
- **אין צורך ליצור קבצי `.cpp`** — כל המימוש בתוך קבצי ה-header (דרישה של תבניות)

## הוראות קימפול והרצה

### שימוש ב-Makefile:
הפרויקט כולל `Makefile` שמאפשר קימפול והרצה בקלות:

```bash
make        # מקמפל ומריץ את התוכנית הראשית
make test   # מקמפל ומריץ את בדיקות היחידה
make clean  # מנקה את כל קבצי הקימפול
```


## טיפים להשלמת המטלה
- קראו היטב את הוראות המטלה והבינו את הדרישות
- **סדר מימוש מומלץ:** מומלץ לממש קודם את `Container.hpp` (כולל Iterator), לאחר מכן `Stack.hpp` ו-`Queue.hpp`, ולבסוף `Algorithms.hpp` — כי Stack, Queue והאלגוריתמים תלויים ב-Container
- **תבניות חייבות להיות מוגדרות בקבצי header** — הקומפיילר צריך לראות את המימוש בזמן שהוא מנסה ליצור instance של התבנית
- **הודעות חריגות:** יש להשתמש בהודעות המדויקות המצוינות בתיעוד ה-`@throws` בכל קובץ (למשל: `"Index out of range"`, `"Stack is empty"`, `"Queue is empty"`)
- איטרטור צריך לתמוך באופרטורים: `*` (dereference), `++` (prefix), ו-`!=` (comparison)
- `begin()` מחזיר איטרטור לתחילת המכולה, `end()` מחזיר איטרטור לסוף (אחרי האיבר האחרון)
- שימו לב שניתן להשתמש ב-range-based for loop כשיש `begin()` ו-`end()`
- בדקו את התוכנית עם מקרי קצה ותנאים שונים
- הקפידו על כתיבת קוד נקי, קריא ומתועד היטב
